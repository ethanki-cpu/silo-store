# Vision

Silo Platform은

온라인 쇼핑몰이 아니다.

커뮤니티 사이트도 아니다.

블로그도 아니다.

SNS도 아니다.

"Silo Store"

"Salon des Cent"

그리고 수십 년 동안 수집한 문화 아카이브를

하나의 살아있는 플랫폼으로 만드는 것이 목적이다.

# 플랫폼의 목표

모든 콘텐츠를

평생 보존 가능한 형태로

아카이빙한다.

모든 콘텐츠는

서로 연결된다.

사람은

콘텐츠를 소비하는 것이 아니라

자신만의 컬렉션을 만든다.

회원들은

자신의 이야기

좋아하는 예술

좋아하는 시대

좋아하는 책

좋아하는 음악

좋아하는 장소를

평생 기록한다.

Silo Platform은

문화를 기록하고

공유하고

큐레이션하는 플랫폼이다.
